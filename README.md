# 🎮 Simon Says — Challenge Your Memory!

> **Watch it. Remember it. Repeat it!** 🧠

Welcome to **Simon Says**, a fun and interactive memory game where every round challenges you to remember and repeat an increasingly longer sequence of colors.

Pay attention, trust your memory, and try to beat your highest level!

## ✨ Features

* 🎨 **Interactive Gameplay:** Click the colored buttons to repeat the displayed sequence.
* 🧠 **Memory Challenge:** Remember increasingly longer sequences as you progress.
* 📈 **Level Progression:** Advance to the next level by correctly repeating the sequence.
* ⚡ **Instant Feedback:** Know immediately whether your answer is correct.
* 🎮 **Simple Controls:** Easy to learn and fun to play.
* 🌐 **Browser-Based:** Play directly in your web browser without installing additional software.

## 🛠️ Technologies Used

| Technology | Purpose                                                                               |
| ---------- | ------------------------------------------------------------------------------------- |
| HTML5      | Structures the game interface.                                                        |

| JavaScript | Implements game logic, sequence generation, user interactions, and level progression. |

## 🚀 Getting Started

Follow these steps to run the game on your computer.

### Prerequisites

* A modern web browser, such as Google Chrome.
* Git installed on your computer (optional).

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the HTTPS URL of your GitHub repository.

**2. Open the project folder**

```bash
cd simon-says-game
```

**3. Launch the game**

Open `index.html` in your web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension if you have it installed.

## 🎯 How to Play

1. Start the game.
2. Watch the button sequence carefully.
3. Repeat the sequence by clicking the buttons in the same order.
4. Complete the sequence correctly to advance to the next level.
5. Remember that each new level adds another challenge!
6. Make a mistake, and the game ends. Try again to beat your previous record!

**Your goal:** Reach the highest level you can!
